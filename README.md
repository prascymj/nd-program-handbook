# คู่มือบริหารหลักสูตรบัณฑิตพันธุ์ใหม่ (Non-Degree)

คู่มือนี้อธิบายงานบริหารหลักสูตรหนึ่งรุ่น ตั้งแต่เขียนข้อเสนอจนปิดโครงการ เนื้อหาสรุปจากการดำเนินงานจริงของหลักสูตร ADT-RAISE รุ่น 1 (2568) และรุ่น 2 (2569) ของสำนักวิชาเทคโนโลยีดิจิทัลประยุกต์ มหาวิทยาลัยแม่ฟ้าหลวง

## เนื้อหา

- ภาพรวมและปฏิทินทั้งรุ่น
- ใครทำอะไร
- โครงสร้างไฟล์
- ขั้นตอนตามช่วง P1 ถึง P8
  - ข้อเสนอ
  - ออกแบบหลักสูตร
  - รับสมัคร
  - เตรียมก่อนเปิด
  - ดำเนินการรายโมดูล
  - ประเมินผล
  - ใบประกาศ
  - ปิดโครงการ
- การเงิน
- เอกสารและการอนุมัติ
- เช็กลิสต์
- บทเรียน

อัตราเบิกจ่ายและผู้มีอำนาจลงนามอาจเปลี่ยนตามระเบียบใหม่ ตรวจกับฝ่ายการเงินของหน่วยงานทุกครั้ง

## แก้ไขและสร้างใหม่ (สำหรับผู้ดูแล)

แก้เนื้อหาที่ `src/pages/*.html` แก้หน้าตาที่ `src/style.css` แล้วรัน

```
python3 build.py
```

ไฟล์ที่ได้อยู่ใน `site/` ใช้เผยแพร่ผ่าน GitHub Pages
